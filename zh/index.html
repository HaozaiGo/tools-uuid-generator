UUID Generator 是什么？

一个支持 UUID v4、v7、v1 的批量生成器，可设置大小写、连字符、引号、花括号和逗号分隔格式。

主要功能

  • Generate UUID v4 values
  • Generate UUID v7 time-ordered values
  • Generate UUID v1 timestamp values
  • Create up to 10,000 UUIDs at once
  • Choose uppercase, braces, quotes, and comma formats
  • Copy or download generated UUIDs

适合场景

  • 开发、调试或发布前的日常处理
  • 在浏览器端快速完成任务，减少数据上传
  • 为技术文档、测试数据或线上内容做准备

示例工作流

  1. 先选择 UUID 版本和需要生成的数量。
  2. 按数据库或接口要求选择大小写、大括号或连字符格式。
  3. 先生成一小批，确认格式符合当前系统。
  4. 最后再复制或下载，用于测试数据、迁移或样例。

安全使用提示

  • UUID 是标识符，不等于访问控制或授权。
  • 不要在公开 ID 中编码个人信息或业务含义。
  • 公开资源仍然需要正常的登录、权限和后端校验。

常见问题

什么是 UUID？

UUID 是一个 128 位标识符，用于在分布式系统中唯一标识数据。

UUID v4 和 v7 有什么区别？

v4 是随机 UUID；v7 带时间排序特性，更适合数据库索引。

生成过程安全吗？

工具使用浏览器加密随机 API 生成随机值，无需网络请求。

一次最多生成多少个？

支持一次批量生成最多 10,000 个 UUID。
